# Relatório técnico

Esta pasta contém o relatório técnico final do projeto **Brain MRI Segmentation**:

- [Relatorio_Tecnico_Brain_MRI_Segmentation.pdf](Relatorio_Tecnico_Brain_MRI_Segmentation.pdf)

O relatório apresenta o dataset LGG MRI Segmentation, a preparação dos dados (incluindo a divisão por paciente), os três experimentos realizados, os resultados quantitativos e qualitativos e as conclusões do projeto.

Os resultados descritos no relatório correspondem aos do notebook [`notebooks/Brain_MRI_Segmentation.ipynb`](../notebooks/Brain_MRI_Segmentation.ipynb) e do arquivo [`results/experiment_comparison.csv`](../results/experiment_comparison.csv). Para a visão geral do projeto, consulte o [README principal](../README.md).
